# Community code of conduct

Be respectful, specific and constructive. Welcome people with different backgrounds
and experience levels. Critique ideas and code without personal attacks. Respect
privacy and other people's time.

Harassment, threats, discriminatory abuse, unwanted sexual attention, deliberate
misrepresentation and publication of private information are not acceptable.
These expectations apply to project issues, pull requests and project discussions.

Report conduct concerns privately to contact@smithlabs.ai. Maintainers will assess
reports with discretion and may clarify expectations, remove content, restrict
participation or block repeat offenders. Decisions should reflect the severity and
context of the behavior. Disagreeing respectfully with a technical decision is not
a violation. If a concern involves a maintainer, say so in the report so another
available maintainer can consider it.
