# Governance

Smith Labs, LLC maintains SmithGuard and is responsible for the hosted service.
Maintainers choose project scope, review contributions and make release decisions.
Contributors retain authorship of their work. Participation does not grant cloud,
database, credential or production access.

Use issues and pull requests for ordinary design discussion. Record substantial
decisions in the affected documentation so future contributors can understand the
tradeoff. Sensitive vulnerability and conduct reports use the private channels in
SECURITY.md and CODE_OF_CONDUCT.md.

There is no promised release cadence, support term or acceptance deadline. Public
source changes and hosted deployments are separate events. Release notes should
identify behavior changes, migrations, compatibility limits and security fixes
without revealing exploit-sensitive or private operating details prematurely.
